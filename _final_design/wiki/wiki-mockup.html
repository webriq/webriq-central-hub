PipelineForge — Overview & Architecture

Edited by Nikki Gabato
Updated Sep 8, 2026 v2 · Sprint 1C pipelineforge architecture sprint-1

This page documents what PipelineForge does, how it's built, and where to look for setup and API details. It's the entry point for anyone new to the product.

💡 Every product space follows the same page set: Overview & Architecture → Setup & Config → API Reference → Changelog. Keep new products consistent with this shape.

Purpose

Give every team a single place to document each product's decisions, specs and processes — searchable from the same "Ask anything" bar used across the rest of the Hub.

Structure

  • Spaces — one per product (PipelineForge, PublishForge, CiteForge, StackShift I, StackShift II, Citation Grader)
  • Pages — nested, versioned documents inside a space
  • Blocks — headings, callouts, code, tables and embeds inside a page
